# Nooagram 更新检查

正式版通过 GitHub Releases 的 `latest/download/update.json` 检查新版。
发布操作不会向设备发送推送消息。

- 启用自动检查且没有检查记录时，首次进入前台立即检查。
- 检查成功后间隔一小时再次检查；没有新版也属于成功。
- 请求失败后间隔五分钟重试，不修改上次成功时间，也不清除已发现的新版。
- 应用在前台时安排下一次检查，退到后台时取消定时任务。
  再次回到前台时，已到检查时间就立即执行，否则等待剩余时间。
- 成功和失败时间分别保存在配置中，进程重启后继续遵守相应间隔。
- 手动检查绕过时间间隔和自动检查开关。已有请求正在执行时复用该请求，
  完成后仍显示手动检查结果。
- 自动检查关闭时不安排定时任务；Migration Test 不自动获取正式更新。

调度逻辑位于 `NooagramUpdateCheckScheduler`，由 `LaunchActivity` 接入生命周期、
请求和界面反馈，`SharedConfig` 保存检查时间。
`NooagramUpdateCheckSchedulerTest` 使用可控时钟验证间隔边界、失败重试、
前后台切换、进程重启后的时间记录和手动检查。
