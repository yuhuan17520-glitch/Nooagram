# Nooagram 1.3.2

本版集中修复下载、设置开关、云备份与通知行为中的用户可见问题。

- 手动下载普通文件统一保存到 `Download/nooagram`，作为唯一正式文件；缓存和看图数据不会混入该目录。
- 修复通用设置与 Ayu 设置中的共享开关状态不一致的问题，从任一处修改后保持一致。
- 修复云备份因 `DATA_TOO_LONG` 失败的问题：分片现在按实际 UTF-8 请求长度计算，并避免自动同步失败时重复弹出提示；手动同步仍会返回明确结果。
- 修复清除通知后重新打开应用时旧通知重复出现的问题；新消息通知不受影响。
