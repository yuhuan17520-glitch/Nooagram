# Nooagram 1.4.0

本版基于 Telegram 13.1.1，并修复了一次全量代码审计中确认的 65 个问题，涉及消息归档、过滤与通知、幽灵模式、下载导出和界面卡顿。

上游更新：

- 同步 Nagram 开发分支（build 1257），Telegram 版本从 13.0.2 升级到 13.1.1。
- 包含上游新增的成员头像、提及和成员列表上的管理员操作，贴纸形状，常规设置里的文件夹标签实时预览，聊天设置里的双击操作实时预览，以及在区块链浏览器中打开钱包地址。
- 包含 Telegram 官方修复：从其他应用分享多个文件、“以文件发送”、Instant View 链接遵循内置浏览器设置、常驻机器人键盘时系统返回键无效等。

消息归档：

- 删除某个编辑版本时，不再连带删掉其他版本和当前消息的缓存文件。
- 编辑替换媒体后，旧媒体会先存进编辑历史再删除；未署名的频道帖编辑也会保存。
- 多账号同在一个群时，一个账号的删除不再让另一个账号漏存已删除消息；退出登录后新账号不会看到上一个账号的归档预览。
- 清空历史或数据库后，排队中的保存任务不再把旧记录写回；修复合并数据库与附件裁剪之间可能出现的死锁。
- 重复入库、编辑历史附件、缩略图、反应记录不再留下孤儿数据；合并进来的附件会参与清理和容量限制。
- 密聊预览显示最新的已删除消息；频道“可用消息”更新不再把已归档的消息移出聊天界面。

过滤与通知：

- 修复规则读取与修改并发时的崩溃。
- “忽略已屏蔽用户”在关闭正则过滤时也会生效。
- 编辑成命中规则的消息不再出现在汇总通知里；后台收到的相册整组屏蔽；推送不再因规则命中发送者名字而误屏蔽。
- 从文件或云端恢复设置后，过滤规则立即生效；导出包含被屏蔽的群组和频道，导入旧格式保留每个聊天的开关。
- 会话列表在规则加载期间先显示占位，不再闪出原始预览。

幽灵模式与转发：

- 修复旧版设置迁移读错键名，升级后“发送已读动态”“上线后发送离线”不再回到默认值。
- 单聊例外对语音、圆视频的已读请求和密聊生效；用户与群组的例外不再互相冲突。
- “标为未读”不再被拦截；拦截浏览请求时不再出错。
- 顺序转发按服务器的真实结果统计失败；相册转发中途失败不会让分组一直不发出；纯 emoji 和已翻译消息不再被丢弃。

下载与存储：

- 聊天里下载的高清照片会正确导出。
- 一个账号移动共享文件后，另一个账号的引用不会失效；外部存储上的缓存可以正常恢复。
- 取消后立即重试大文档，下载状态不再被旧任务清掉。
- 旧媒体目录的缓存继续计入容量上限并参与清理；长文件名按字节截断，导出失败会清理残缺文件。

性能与界面：

- 回复补全、已删除消息页、阅后即焚媒体解密、会话列表过滤、附件容量调整、规则编辑都移到后台执行，不再卡住界面。
- 已删除消息页的删除操作对准正确的条目，翻页不再强制滚回原位。
- 更新检查不再占用共用的后台队列；强制更新页可以下载 APK；切换账号后下载进度正常显示。
- 关闭高刷新率后旋转屏幕不会重新打开；设置页复制的链接可以打开；共享链接页不再丢失遮罩的链接。
