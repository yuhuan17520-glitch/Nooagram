# Nooagram 1.5.1

本版修复从云端恢复设置失败，以及登录页仍显示 Nagram 名字的问题。

修复：

- 修复“从云端恢复”总是提示“无法从云端恢复设置”的问题。设置过正则过滤规则的用户都会遇到，“导入设置”文件和旧版过滤规则迁移也受同一问题影响，现已一并修复。
- 登录页（欢迎页）标题改为显示 Nooagram，不再显示上游的 Nagram 标志。
- 恢复设置失败时，提示会附带具体错误类型，便于排查。
