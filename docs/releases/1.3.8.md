# Nooagram 1.3.8

改进自动更新提醒，减少正式版发布后需要手动检查才能发现新版的情况。

- 启用自动检查且没有检查记录时，首次进入前台立即检查更新。
- 自动检查间隔统一为一小时；持续在前台使用时也会定时检查。
- 请求失败后五分钟重试，不再因一次失败而等待一天。
- 失败不会清除已经发现的新版提示，检查时间在重启后继续保留。
- 退到后台时取消定时任务，返回前台后按剩余时间继续检查。
- 手动检查绕过时间间隔和自动检查开关；已有请求时复用并显示结果。
