# Nooagram 1.3.6

修复底部个人资料头像变黑和标题居中偏移，并统一下载与保存设置。

- 账号缓存尚未准备好时使用已保存的账号资料绘制头像，返回前台、头像或昵称更新时刷新。
- 修复「标题居中」被主界面强制关闭的问题，切换后即时刷新，动态折叠标题同步对齐。
- 无状态图标时去除右侧空白占位，避免标题文字看起来偏左。
- AyuMoments 与 N 设置共用「下载与保存」页面，提供明确的开关和完整保存位置。
- 在同一保存目录弹窗中支持输入完整路径或点击「选择目录」，通过系统选择器选择文件夹并保留访问授权。
- 内部普通文件目录恢复为应用目录下的 `files/Telegram/`，兼容读取原 `files/documents/` 中的已有文件。
- 默认位置为 `/sdcard/Download/Nooagram/`；保留用户已保存的自定义目录和关闭选项。
- 手动下载的文件、图片、视频和音频完成后保存到指定目录，可按会话建立子目录。
- 避免重试产生重复的媒体副本，同名文件使用新名称；保留播放缓存和已有文件。
