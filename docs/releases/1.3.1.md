# Nooagram 1.3.1

本版汇总 2026-10-23 审计中已经修复并通过针对性验证的问题。其他尚未并入或尚未完成验收的修复不计入本说明。

- 修复已删除消息颜色选择器抢占设置页纵向滚动的问题；横向手势仅在抬手仍位于起始色块时生效，离开色块、横转纵或取消手势不会误保存。
- 修复 AyuMoments 设置链接与设置备份链接无法定位/导入的问题，`nasettings/ayumoments` 现在路由到对应设置页。
- 修复自定义设置页在进程被回收后回到主设置列表的问题；恢复时保留当前自定义设置页类型，并为两类设置基类的派生页保留类名与无参构造，Release DEX 检查会验证该反射合约。
- 修复历史 Ayu 数据库从 v29 升级到 v31 时 `DeletedDialog` 数据丢失的问题；迁移现在保留删除记录、索引和表结构。
- 编辑历史入口与查询移出 UI 线程阻塞路径，由 `Utilities.globalQueue` 后台队列读取，并在 UI 线程提交最新快照，避免菜单操作同步访问 Room。
- 附件目录初始化失败时不再静默写入不受配额和清理管理的内部路径；清理统计改用后台缓存/异步统计，避免同步递归阻塞主线程。
- 完善媒体保存取消与异常清理：取消令牌贯穿下载与写入链路，异常路径关闭流并回滚半成品；Android 9 及以下同名文件冲突时继续递增后缀，不再截断到固定数量。
- 将 Ghost 配置与排除配置纳入设置备份，导入前完整校验所有分块，云同步仅在全部 chunk、元数据和更新时间均成功后才报告成功。
- 修复过滤结果回退时正文消息与日期不一致的问题；相册消息会先确认完整相册上下文再应用过滤，相关 44 项回归探针通过。目标消息加载失败后会释放置顶栏更新状态；普通置顶跳转闪烁仍未宣称完全消除。
- 清理阿拉伯语和乌克兰语中的旧 Nagram 品牌提示，并移除首页标题与故事栏使用的旧 Nagram wordmark；默认标题和故事栏现在显示正常的 Nooagram 文本，同时保留自定义标题。
- 补齐 `UpstreamChannel` 与 `UpstreamTipsChannel` 的现有本地化资源，避免这些设置标签回退英文。
- 保留历史默认保存目录 `Nagram`，避免产品名称更新改变保存文件和默认附件的目录；已有自定义目录保持不变。
- 收窄通用文案的品牌翻译白名单，保留 `About`、`RemoveTitleEmoji` 等通用文案的云端翻译能力，同时继续保护实际包含产品品牌的文案。
- 签名候选流水线改为从 `nooagram-version.json` 读取版本号与版本名，版本 floor 提升后不会因 workflow 硬编码而构建失败。
