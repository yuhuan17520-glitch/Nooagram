# Nooagram 1.3.7

修复内部下载目录的分类结构。`files/Telegram/` 作为根目录，文件按类型保存到对应子目录。

- ZIP、APK 和普通文档保存到 `files/Telegram/Telegram Documents/`。
- 图片、音频和视频分别使用 `Telegram Images/`、`Telegram Audio/` 和 `Telegram Video/`。
- 其他内部文件和动态分别使用 `Telegram Files/` 和 `Telegram Stories/`。
- 修复带原始文件名的媒体被统一写入文档目录的问题。
- 兼容读取原有分类目录，以及此前保存在 `files/documents/` 和 `files/Telegram/` 根目录的文件。
- 旧文件缺失或大小不符时，重新下载到对应分类目录，保留旧文件内容。
- 保留用户自选保存目录、系统目录授权和公共下载保存设置。
