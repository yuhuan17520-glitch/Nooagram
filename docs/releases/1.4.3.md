# Nooagram 1.4.3

本版修复查看图片时图片被自动保存到相册的问题。

下载与保存：

- 点开或查看图片、播放视频时，不再把文件复制到下载目录（默认 `Download/Nooagram`），相册里不会再多出看过的 Telegram 图片。
- 开启“自动保存手动下载的文件”时，只有点消息上的下载按钮下载的文件、视频和音频才会保存到设置的目录。
- 图片没有单独的下载按钮，点开只是查看；需要保存时使用菜单里的“保存到相册”。
- 已经保存到下载目录的文件不会被删除，可按需自行清理。
