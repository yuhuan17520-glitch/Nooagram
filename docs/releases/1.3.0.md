# Nooagram 1.3.0

迁移至 NextAlone/Nagram，基于 Telegram 13.0.2 / Nagram 1255，保留 AyuMoments。

- 修复迁移后设置文字显示 LOC_ERR，以及设置项长按导致的类型转换崩溃。
- AyuMoments 开关仅在开关附近切换，减少滚动时误触；导航入口和无障碍操作保留。
- 修复数据库导入、导出等导航行误显示开关、点击文字无法进入的问题。
- 修复附件目录名称过长覆盖标题的问题。
- 保留消息过滤后的主页预览回退、置顶跳转和菜单阴影修复。
- 保持 Nooagram 正式包名与原签名，支持覆盖升级；最低 Android 8.1。

上游固定提交：87863c8a57854c739e1452e56591c07ea52415d3。

升级前建议在 AyuMoments 中导出消息数据库并保存设置备份。旧 XF 翻译和网络缓存没有转换到新缓存格式；原缓存文件保留。独立 Migration Test 应用需要单独保留，正式版无法继承它的登录状态。

提供 arm64-v8a、armeabi-v7a、x86_64 三个安装包，以及 SHA256SUMS.txt 和兼容旧客户端的 update.json。发布前验证记录见同目录 125001000-validation.md；未执行的测试不包含在验证声明中。
