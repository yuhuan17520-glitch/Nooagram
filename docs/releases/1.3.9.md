# Nooagram 1.3.9

被消息过滤规则命中的消息不再弹出通知。

- 命中正则过滤规则的消息不再推送通知，“隐藏消息”和“遮罩消息”两种模式都生效。
- 来自已屏蔽用户或频道的消息，在遮罩模式下也不再推送通知。
- 冷启动恢复未读通知、通知分组重建时同样跳过被过滤的消息。
- 推送预览只用于判断通知，过滤结果不写入缓存，不影响聊天内的正常匹配。
- 关闭消息过滤后通知行为与之前一致；自己发出的消息不受影响。
