# Nooagram 1.3.3

本版修复通知关闭状态与过滤会话尾部已读边界问题。

- 修复过滤广告尾部时未读角标和向下箭头无法安全清除的问题；在 Ghost 模式或已离开会话底部时，不会因此把未读消息误标为已读。
