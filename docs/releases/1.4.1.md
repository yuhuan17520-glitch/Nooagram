# Nooagram 1.4.1

本版修复会话列表里被过滤消息的预览问题，并清理存储目录里多余的文件。

会话列表预览：

- 最新消息被过滤、又找不到可显示的消息时，预览显示“消息已过滤”，不再长时间停在“正在查找上一条未被过滤的消息”。
- 相册（一次发送的多张图片或多个文件）的预览不再在“正在查找”和正常消息之间来回闪烁；编辑或删除其他消息不再让所有相册重新检查。
- 相册还在检查时，先按设备上已有的内容判断：已有内容命中规则就立即替换，否则正常显示，检查完成后再更正，不再显示空白。
- 整个会话都被过滤时，不再每 60 秒在后台重复拉取历史消息；有新消息或规则变化时才重新查找。
- 规则加载期间不再长时间锁住缓存，打开会话列表更流畅。

存储：

- 不再在 `Telegram` 根目录生成 `.nomedia` 文件，旧版本留下的空文件会在启动时自动删除；`Images`、`Video` 等子目录里的 `.nomedia` 保留，媒体仍不会出现在相册中。
