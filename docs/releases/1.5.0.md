# Nooagram 1.5.0

本版基于 Telegram 13.2.2，修复加入群组和频道时总是提示“达到上限”的问题。

加入群组：

- 修复加入任何群组或频道都提示“达到上限”（`CHANNELS_TOO_MUCH`）的问题。原因是之前沿用的上游 API ID 被 Telegram 服务器限制；本版改用 Nooagram 自己的 API ID。
- API ID 在登录时绑定到会话。**已登录的账号需要退出后重新登录一次才会生效**，否则加群仍会提示达到上限。退出前请确认记得两步验证密码，或者有其他已登录的设备可以接收验证码。
- 开启“本地 Premium”时，达到上限的提示会显示服务器的真实上限（例如 500），不再显示 Premium 的 1000。
- 多账号时从邀请链接加群，会使用打开链接的那个账号，出错时也会显示正确的提示。

上游更新：

- 同步 Nagram 开发分支（build 1260），Telegram 版本从 13.1.1 升级到 13.2.2。
- 包含上游新增的：隐藏回复已屏蔽用户的消息（实验设置）、跳转到置顶消息后返回原阅读位置、例外列表显示是谁限制了该用户、头像圆角和消息气泡尾巴的设置与实时预览。
- 包含 Telegram 官方和上游修复：投票前显示票数、头像圆角缩放、主标签页关闭时启动崩溃等。
